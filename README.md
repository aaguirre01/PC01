## Instrucciones de ejecución
1. Clonar el repositorio
2. Abrir en Android Studio
3. Configurar Firebase con el archivo google-services.json
4. Ejecutar en dos emuladores/dispositivos
5. Crear dos usuarios en Firebase Authentication
6. Crear el sorteo en Firestore (draws/sorteo_001)
7. Iniciar sesión en ambos dispositivos
8. Registrar jugadas diferentes
9. Cambiar estado del sorteo y publicar bolillas desde Firebase Console

## Tecnologías
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore (tiempo real)
